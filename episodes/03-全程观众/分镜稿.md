# 分镜稿 03：全程观众（第 3 版）

状态：分镜稿待确认（确认前不写动画代码）

第 3 版改动：不再用需要复杂人物场景的电影院，改为「人生拼图」。画面只用三种元素：拼图块、日常物件图标、文字。每种元素都简单、具体、一眼能看懂，也能稳定做出好效果。

## 1. 基本信息

- **主题**：全程观众——别人手里只有你人生拼图的几块，只有你自己拿着完整的一副
- **时长**：约 61 秒（1920×1080，30fps，无声，无水印）
- **一句话核心观点**：每个爱你的人都只参与了你人生的一段，唯一从头看到尾的是你自己，所以把时间和精力花在自己身上。
- **标题卡**：中文「全程观众」，英文副标题 `THE ONLY ONE WHO SAW IT ALL`

## 2. 数据来源

- 本期是情感叙事，**不使用数据图表**，没有引用数据。

## 3. 核心意象：人生拼图

- 一副 2 行 × 4 列、共 8 块的拼图，按时间顺序排列，每块上是一个代表人生阶段的**物件图标**：

| 块 | 阶段 | 物件 |
|---|---|---|
| 1 | 婴儿 | 奶瓶 |
| 2 | 童年 | 书包 |
| 3 | 少年 | 学士帽 |
| 4 | 青年 | 公文包 |
| 5 | 青年 | 婚戒 |
| 6 | 中年 | 婴儿车 |
| 7 | 暮年 | 老花镜 |
| 8 | 暮年 | 摇椅 |

- 每块下方有一行等宽小字写阶段名（婴儿、童年……），观众不用猜。
- **谁看过哪一段**：每种关系是一副拼图，只有看过的那几块在，没看过的位置是一个黑洞（只留一圈拼图形状的虚线轮廓）。拼图上方写关系名：父母、伴侣、儿女、朋友。
- **完整的人生**：只有标着「你」的那一副，8 块全部拼齐。

**画法**：拼图块用 SVG 画，带凹凸边、轻微厚度和柔和阴影，像一块块真的拼图；物件图标是扁平填色图标（不是线条），统一风格。拼图块的飞散、拼合、光晕用 Canvas 2D。文字用 HTML/CSS（思源宋体 Heavy，逐字模糊转清晰）。
