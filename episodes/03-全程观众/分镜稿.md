# 分镜稿 03：全程观众

状态：分镜稿待确认（确认前不写动画代码）

## 1. 基本信息

- **主题**：全程观众——别人只见过你人生的片段，只有你自己看完了全程
- **时长**：约 61 秒（1920×1080，30fps，无声，无水印）
- **一句话核心观点**：每个爱你的人都只参与了你人生的一段，唯一从头看到尾的是你自己，所以把时间和精力花在自己身上。
- **标题卡**：中文「全程观众」，英文副标题 `THE ONLY ONE WHO SAW IT ALL`

## 2. 数据来源

- 本期是情感叙事，**不使用数据图表**，没有引用数据。
- 「人生长卷」上的年龄刻度（0、6、18、30、45、60、80 岁）只是**示意**，不代表统计数据，画面角落用等宽小字标注「示意」。

## 3. 贯穿全片的核心意象：人生长卷

一条横贯画面的细长光带，从左到右是一个人的一生：婴儿 → 孩童 → 少年 → 青年 → 中年 → 老年。光带上用简洁的白色线描人物剪影标出六个阶段，平时整条是暗的（灰白描边、低亮度）。

- 每一种关系是一束「目光」，只能照亮光带上的一段——这就是「只见过你的一部分」。
- 照亮的那段会碎成玻璃碎片，碎片里是那段人生的具体画面——这就是「零碎的片段」。
- 只有「你自己」的光点能从最左端走到最右端，整条长卷全部亮起——这就是「完整的人生」。
- 结尾回到这条长卷，形成闭环。
