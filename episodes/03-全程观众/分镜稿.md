# 分镜稿 03：全程观众（第 2 版）

状态：分镜稿待确认（确认前不写动画代码）

第 2 版改动：核心意象从「人生长卷」改为「电影院」；所有具体内容改用扁平插画（完整的人物、场景、道具），不再用线条和光点表示。

## 1. 基本信息

- **主题**：全程观众——别人只看过你人生电影的几段，只有你自己从片头坐到现在
- **时长**：约 61 秒（1920×1080，30fps，无声，无水印）
- **一句话核心观点**：每个爱你的人都只参与了你人生的一段，唯一从头看到尾的是你自己，所以把时间和精力花在自己身上。
- **标题卡**：中文「全程观众」，英文副标题 `THE ONLY ONE WHO SAW IT ALL`

## 2. 数据来源

- 本期是情感叙事，**不使用数据图表**，没有引用数据。
- 银幕下方进度条上的年龄刻度只是**示意**，不代表统计数据。

## 3. 核心意象：一场叫「你的人生」的电影

- **放映厅**：暗色放映厅，镜头位于观众席后方偏高处。上方是银幕，下方是几排深红色绒面座椅（看到椅背和观众的后脑勺、肩膀）。画面下方约 1/6 留给字幕。
- **银幕**：放的是主角的一生，每个镜头都是完整的扁平插画场景（见各分镜）。
- **进度条**：银幕正下方一条细进度条，像播放器一样，下方标「童年 · 少年 · 青年 · 中年 · 暮年」，帮助观众知道电影放到了哪。
- **座位上的人**：父母、伴侣、儿女、朋友在不同的时候进场、离场。只有中间那个座位上的主角，从片头一直坐着。
- **片段**：离场的人手里只带走几格胶片，胶片上是他们看过的那几段——对应「零碎的片段」。

## 4. 插画风格与制作方式

**风格**：扁平插画，色块填充加柔和渐变阴影。人物有五官、发型、衣服和动作，一眼能看出是谁、在做什么。不用线描小人，也不用光点代替人物。

**角色设定**（全片统一，观众能认出是同一个人）：

- **主角**：短发，各年龄段都穿芥末黄的上衣或围巾（呼应金黄主色）。出现五个年龄版本：婴儿、小学生、穿校服的少年、穿西装的青年、两鬓斑白的老人。
- **父母**：父亲穿深蓝夹克，母亲穿酒红针织衫；先出现年轻版，后出现中年版。
- **伴侣**：浅灰色风衣。
- **儿女**：一儿一女，先是小孩，后是少年。
- **朋友**：三四位，衣服颜色各不相同。

**配色**：放映厅以深蓝黑、暗酒红为主，压得很暗；银幕里的场景用自然色，亮度适中，作为画面焦点。文字仍按指南：金黄 `#F5D76E`、红 `#E8483A`、白 `#F2F2F2`。

**制作方式**：

- 人物、场景、座椅用 **SVG** 绘制，做成可复用的部件，用 CSS transform 做走路、坐下、转头等动作。
- 放映机光束、银幕反光、胶片飞出、灰尘粒子、暗角用 **Canvas 2D**。
- 字幕、标题卡用 **HTML/CSS**（思源宋体 Heavy，逐字模糊转清晰）。
- 所有动画都按时间 t 计算，保证逐帧渲染结果一致。
